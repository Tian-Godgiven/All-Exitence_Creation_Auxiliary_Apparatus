# 开发计划

基于项目分析和公测阶段目标整理。当前阶段的核心目标是：**让已有功能用起来不别扭**，而不是加新功能。

---

## 第一阶段：修复影响用户体验的 Bug

> 这些是用户现在就能感知到的问题，优先级最高。

### 1.1 页面滑动 pointer/touch 双重触发
- **问题**：App.vue 同时绑定 `@touchmove` 和 `@pointermove`，移动端一次滑动触发两次 `movePage`，位移叠加
- **修复**：统一使用 pointer 事件，移除 `@touchmove` 绑定
- **文件**：`App.vue`、`hooks/app/appTouch.ts`
- **预估**：半小时

### 1.2 DraggableList 的 Symbol() key
- **问题**：`:key="Symbol()"` 导致每次渲染所有子组件被销毁重建，列表性能差
- **修复**：改用 item 的 `__key` 作为 key
- **文件**：`components/other/DraggableList.vue`
- **预估**：10 分钟

### 1.3 分组规则 || 短路 bug
- **问题**：`if(result == false) return false` 导致 `||` 连接符永远无法将 false 救回 true
- **修复**：仅在 `&&` 和 `!` 连接符下提前中断
- **文件**：`hooks/expression/groupRule.ts`
- **预估**：15 分钟

### 1.4 分组规则 setting 取值错误
- **问题**：第 163 行 `return exitence.setting.setName` 读取字面量而非正则匹配结果
- **修复**：改为 `exitence.setting[setName[1]]`
- **文件**：`hooks/expression/groupRule.ts`
- **预估**：5 分钟

### 1.5 浮动按钮调试代码残留
- **问题**：`console.log(clickButton, longTap, moving, click)` 还在代码里
- **修复**：删除
- **文件**：`components/floatWindow/floatButton.vue`
- **预估**：1 分钟

## 第二阶段：拖拽排序迁移到 SortableJS

> 删代码比写代码多的改进，做完之后代码量减少，维护负担减轻，移动端拖拽体验提升。

### 2.1 在简单列表上试点
- 选一个简单的列表（如标签组排序）用 vuedraggable 替换
- 验证移动端触摸拖拽体验
- **预估**：半天

### 2.2 逐步替换所有使用点
- 替换左侧面板的分类/事物排序
- 替换弹窗里属性列表排序
- 替换其他 DraggableList 使用处
- **预估**：1-2 天

### 2.3 处理章节树形拖拽
- 章节的嵌套拖拽用 vuedraggable 的嵌套模式替代 `allowInto` + `level`
- 这是最复杂的部分，需要仔细测试
- **预估**：1 天

### 2.4 清理旧代码
- 移除 `@atlaskit/pragmatic-drag-and-drop` 和 `@atlaskit/pragmatic-drag-and-drop-hitbox` 依赖
- 删除 `api/dragToSort.ts`、`Draggable.vue`、`DraggableList.vue`、`DragNode.vue`、`indicator.vue`
- **预估**：半小时

## 第三阶段：给核心逻辑补测试

> 为后续重构提供安全网。不需要很多，覆盖关键纯函数即可。

### 3.1 搭建测试环境
- 配置 Vitest（与 Vite 生态一致）
- **预估**：半天

- `filterExitenceByRule` — 分组规则匹配（刚修完 bug，正好验证）

- `translateToFileContent` / `translateToFrontEndContent` / `translateToTextContent` — 三层文本转换
- `countExpression` / `explainExpression` — 表达式计算
- `getCustomEqualToUnit` / `translateTimeValueToArr` — 时间单位换算
- **预估**：1-2 天

## 第四阶段：交互体验打磨

> 公测阶段收集到的 UI/交互反馈，以及分析中发现的体验问题。

### 4.1 页面切换动画优化
- 将 `pageChange.ts` 中手写的 requestAnimationFrame 匀速动画改为 GSAP 缓动（项目已引入 GSAP）
- 添加 ease-out 曲线，让滑动回弹更自然
- **预估**：半天

### 4.2 多指触摸保护
- 在 appTouch.ts 中检查是否已有活跃触摸，忽略第二根手指
- **预估**：半小时

### 4.3 浮动按钮事件清理
- 在 floatButton.vue 的 onUnmounted 中兜底移除全局 pointerup 监听
- 处理手指滑出屏幕后 pointerup 的空引用问题
- **预估**：半小时

### 4.4 搜索结果聚焦高亮
- 点击搜索结果跳转到事物/文章时，对应区域高亮显示
- **预估**：1 天

### 4.5 收集真实用户反馈
- 找 1-2 个实际在写长篇的朋友试用
- 观察他们在哪里卡住、困惑
- 记录反馈，纳入后续迭代

## 第五阶段：小规模重构

> 在有测试保护的前提下，逐步改善代码质量。

### 5.1 属性合并逻辑统一
- 当前有三条路径做属性合并（`getFullStatus` 的 `_.merge`、`getExitenceStatusByKey` 的手动展开、`getFullStatusOfExitence` 的包装调用）
- 统一为一个函数，消除 setting 深浅合并不一致的问题
- **预估**：半天

### 5.2 辅助功能持久化统一
- 早期的 quickDraft、inputSuggestion、customTime 各写各的读写逻辑
- 统一使用 `supportAbilitySyncProject` / `supportAbilitySaveProject`（tagLibrary 已在用）
- **预估**：半天

### 5.3 辅助功能生命周期补全
- 添加 `destroy` / `cleanup` 钩子（解决 missionList 的 setInterval 无法清除等问题）
- 添加 `deleteProject` 钩子（删除项目时通知辅助功能清理数据）
- **预估**：半天
