# 后续开发计划

> 当前计划，最后整理：2026-11-05。这里是唯一用于排定后续工作的文档；早期任务与原型文档保留为历史参考，不直接视为待办。

## 当前目标

在继续扩展功能前，优先保证本地项目可可靠保存、既有工具可稳定使用，并按实际创作流程改善检索与组织体验。

## 已完成能力

- 项目本地存储、项目级/应用级回收站与基础项目概览。
- 文章、章节、分类、事物及结构化文本编辑；文章可引用事物。
- 时间线：片段、日期或相对数轴、文章/文本/卡片节点、范围节点、关系连线、时间线回收站及文章侧时间信息。
- 灵感便签板：项目画布与“全部”画布、颜色管理、自由移动缩放、框选、关联连线与快捷记录。
- 全局文字素材库：粗体、斜体、颜色、抖动、模糊、透明、错位及防剧透；支持效果叠加、段落范围与阅读态渐进预览。
- 项目导出：纯文本单文件/章节目录包、AO3 HTML 与 Work Skin CSS、EPUB 3；导出端为不受支持的效果提供可读降级。

## 近期事项

### 稳定性与验收

- [ ] 启用并完善自动保存与退出保存：保存需等待写入队列完成，并能报告失败；当前不能依赖自动保存或关闭应用保存。
- [ ] 按 [回归检查清单](回归检查清单.md) 手动验证项目、回收站、文章树、属性、分组规则与保存重开流程，并记录结论。
- [ ] 修复分组规则已知问题：`||` 的短路逻辑，以及动态设置项名被当作字面量读取的问题。
- [ ] 清理核心路径遗留调试输出和重复的数据合并逻辑。

### 搜索与组织

- [ ] 便签按正文搜索、按颜色筛选。
- [ ] 全局搜索结果跳转后，高亮对应事物或文章文本；点击其他位置取消高亮。
- [ ] 决定“预制属性”入口的去留：实现预设属性选择/管理，或移除当前空实现。
- [ ] 明确嵌套属性选择、属性合并与事物内嵌引用的后续范围。

### 中期体验项

- [ ] 为分类中的事物提供卡片/网格展示方式，作为与现有列表不同的浏览和整理视图；图标、自定义展示样式及拖拽分类另行讨论。
- [ ] 继续将项目大纲发展为项目级的规划工作台，讨论如何表达项目目标与文章/章节结构；不额外创建并行的大纲系统。

### 已有工具的后续优化

- [ ] 时间线：设计上下排列片段的连接表现、隐形网格拖动对齐、节点范围调整，以及章节含不连续时间段时的表达。
- [ ] 文字效果：长文章中大量段落渐进模糊/透明时，使用 `IntersectionObserver` 只为视口附近效果组挂载完整只读阅读层。
- [ ] 导出：图片素材落地后支持 EPUB 封面与插图资源打包；届时为聊天框、论坛体等结构素材定义 AO3/EPUB/纯文本表达。

## 功能储备

- 暂缓：任务清单、计时器、字数目标、创作日历与全局字数统计。它们涉及持续计时、保存可靠性和统计口径，当前不启动设计或实现。
- 暂缓：结构素材中的聊天框、论坛体和图片，以及素材包导入/导出、脚本/外部资源/样式隔离规则；图片素材落地后再补 EPUB 封面与插图资源打包。
- 暂缓：角色关系图、事件导图与世界线管理。关系图需要重新评估事物系统的实际使用体验；世界线需求不明确，置于远期。
- 暂缓：自定义短语、输入辅助栏及自动关键词识别；保持当前事物输入建议和自动补全能力，不额外扩展。
- 远期探索：设定生成器、复杂自定义历法规则（农历、自定义月份/进位等）。当前时间线继续使用相对数轴或固定年月日规则。
- 正式版前的数据备份、恢复、导入与兼容迁移策略；现阶段不导入 EPUB，也不兼容旧 JSON。

## 技术整理

- [ ] 为项目、文章树、事物和属性定义更集中的状态更新入口；逐步收窄核心路径的 `any`。
- [ ] 统一辅助功能的创建、加载、保存、卸载和删除项目生命周期。
- [ ] 评估并收口拖拽排序实现，重点验证移动端手势冲突；不在未确认前替换现有方案。
- [ ] 在领域逻辑和存储层稳定后补充单元测试，并完善发布前手动验收与备份策略。

## 已确认边界

- 应用保持本地离线；暂不引入数据库或网络服务。
- 当前工程文件是可继续编辑的唯一源数据；AO3、EPUB 和纯文本均为导出产物。
- PC 端左侧目录常驻；工具以中间工作区覆盖层按需打开，右键为主要上下文菜单入口，触屏保留长按。
- 每项具体实现仍需在改动前单独讨论确认。
